# Rowan OS Demo

Limited public demo of **Rowan OS** — the personal operating system.

This version includes:
- Cinematic dark design system (film grain, glass panels, gold accent)
- Command Centre dashboard
- Sidebar navigation
- Architecture and schema foundation for Goals, Tasks, Notes

Full private version with complete finance, trading, business modules and working data layer: [rowan-os](https://github.com/MichaelSwann2x/rowan-os) (private).

## Run locally

```bash
npm install
npm run dev
```

Design tokens and UI match the full product. Data is mocked / empty-state for the demo.
