# Rowan OS Demo — Fully Working Live Version

Open `live/index.html` or serve the folder.

## Features that work now

- Full localStorage persistence (survives refresh, tab close, browser restart)
- Brain Backup page: Download complete JSON of all data, Import to restore
- Command Centre, Goals, Tasks, Notes, Habits
- Quick Capture
- Cinematic dark UI with film grain

## Run

```bash
python3 -m http.server 3847
# open http://localhost:3847/live/index.html
```

Or just open the HTML file in a browser.

Full private version with schema for production expansion: https://github.com/MichaelSwann2x/rowan-os
